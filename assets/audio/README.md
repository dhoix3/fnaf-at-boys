Optional sound effects are loaded by `audio_manager.py` when present. Place licensed
`.ogg` or `.wav` files here using these names:

- `ventilation.ogg` — looping office ambience
- `door.wav` — metallic door movement
- `foxy_steps.ogg` — Foxy's sprint cue
- `jumpscare.ogg` — scare sting
- `camera.ogg` — camera-feed switching

Audio is optional; missing files are logged and gameplay continues silently.
